# 題目一：Ackermann Function

## 解題說明

這題要用兩種方法來算 Ackermann Function，一種是遞迴，一種是非遞迴。主程式會一直讀入 m 和 n，然後印出 A(m,n) 的答案。

Ackermann Function 的規則有三種情況：

| 條件 | A(m,n) 的值 |
|------|-------------|
| m = 0 | n + 1 |
| m > 0 而且 n = 0 | A(m-1, 1) |
| m > 0 而且 n > 0 | A(m-1, A(m, n-1)) |

## 解題策略

### 遞迴版本

遞迴版本我是照著規則一條一條寫成 if。

#### 先判斷 m 是不是 0

先看 m 是不是 0。如果是，直接回傳 n + 1，不用再呼叫自己。

#### m 大於 0 並且 n 是 0

改算 a(m-1, 1)，m 會減一。

#### m 和 n 都大於 0

要先算裡面的 a(m, n-1)，算出來的答案當成外面那一層的 n，再去算 a(m-1, 那個答案)。

#### 為什麼一定會停下來

每呼叫一次，m 和 n 都會往比較小的方向走，所以最後一定會碰到 m 等於 0 而停下來。

#### 主程式一次測很多組

主程式用 while (cin >> m >> n) 一直讀資料，讀到沒有資料為止。

### 非遞迴版本

非遞迴版本的想法是，遞迴其實就是電腦幫我們把「還沒做完的事」疊起來，那我們自己疊就好了。
